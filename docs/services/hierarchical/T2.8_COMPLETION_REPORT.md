## 修复的问题

### 问题 1: 服务未注册
**症状**: 运行示例时报错 `ValueError: Service type 'property_graph' not registered`

**原因**: 装饰器注册需要导入服务类才能触发

**解决方案**: 在所有示例文件中添加服务类导入:
```python
from sage.middleware.components.sage_mem.neuromem.services.hierarchical import (
    LinknoteGraphService,
    PropertyGraphService,
)
```

### 问题 2: retrieve() API 不匹配
**症状**: `property_graph_example.py` 运行报错 `TypeError: unhashable type: 'dict'`

**原因**: 示例代码使用了 `query={"entity_type": "Language"}`，但实际 API 期望 `query="", entity_type="Language"`

**解决方案**:
- 修复所有示例代码使用正确的 API
- 更新 README.md 中的示例
