- **CONTRIBUTING.md** - Contribution guidelines
- **NAMESPACE_MIGRATION_GUIDE.md** - Guide for migrating to sage.neuromem namespace

Helper scripts are located in `docs/scripts/`:

- **quickstart.sh** - Quick start script for setting up NeuroMem
- **neuromem_refactor.sh** - Automated refactoring script for namespace migration
- **restructure_for_pypi.sh** - Script for PyPI package restructuring
